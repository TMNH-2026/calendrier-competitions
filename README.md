# Calendrier des compétitions 2026-2027

Calendrier prévisionnel de la ligue de tir Nord/Pas-de-Calais (version 4, à
jour au 17/9/2026), filtrable par public (École de tir), niveau et discipline.
Mis en forme par le Tir Métropole Nord Haubourdin.

- `index.html` : la page, autonome (aucune dépendance hors Google Fonts).
- `calendrier-ligue-2026-2027.json` : les données, copie de
  `src/data/calendrier-ligue-2026-2027.json` du dépôt du site.

Page marquée `noindex` : la version destinée au référencement sera celle du
futur site tmnh.fr.
